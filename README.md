# Website demos

Three static demo sites (plain HTML/CSS/JS, no build step, no dependencies):

| Demo | Folder | Highlights |
|------|--------|------------|
| Restaurant (Ember & Oak) | `demos/restaurant` | Dark theme, tabbed menu, booking form |
| Local service (FreshNest Cleaning) | `demos/cleaning` | Live price estimator, pricing plans, FAQ |
| Portfolio (Mia Hartwell) | `demos/portfolio` | Dark/light toggle, scroll animations, contact form |

Open any `index.html` in a browser. All names and contact details are fictional; forms only validate and show a confirmation.
